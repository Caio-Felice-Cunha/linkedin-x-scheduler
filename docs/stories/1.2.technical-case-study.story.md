## Story

**As a** recruiter or automation engineer, **I want** to inspect the scheduler's manifest, orchestration, adapters, state, and verification model, **so that** I can understand its reliability without connecting a browser.

## Acceptance Criteria

1. The deterministic report remains the first experience and demo mode remains zero-login/zero-write.
2. The page visualizes manifest validation, orchestration, platform adapters, screenshots, reconciliation, idempotency, resume state, and report generation.
3. Demo, dry-run, and live boundaries are explicit and use real public code snippets.
4. Items expose their step trace and representative fixture data without unsafe HTML injection.
5. README and standard actions expose demo, engineering case, source, and local run paths.
6. Existing scheduler tests plus desktop/mobile, keyboard, no-network, injection, secret, and PII gates pass.
