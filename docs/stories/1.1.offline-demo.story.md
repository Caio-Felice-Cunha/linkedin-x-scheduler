## Story

**As a** visitor without a logged-in browser, **I want** to run and inspect a deterministic schedule rehearsal, **so that** I can evaluate the scheduler safely.

## Acceptance Criteria

1. `npm run demo` processes the versioned sample batch without initializing Playwright or CDP.
2. The command accepts an output directory and writes a stable `demo-report.json` with tool, mode, items, steps, status, and summary.
3. Existing dry-run/live behavior and current branch fixes remain intact.
4. A static Pages viewer loads the fixture report and explains the real-browser boundary.
5. Unit, CLI, no-network, viewer, security, and accessibility gates pass.
